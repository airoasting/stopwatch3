# stopwatch3

HTML 파일 하나로 동작하는 스탑워치 두 개입니다. 브라우저에서 파일을 열면 바로 실행됩니다.

## 10초맞히기.html

숫자와 바늘이 사라진 뒤 감으로 정확히 10초에 멈추는 게임입니다.

- 목표 시간 5초 / 10초 / 30초. 앞의 30%만 바늘이 보입니다.
- 스포츠 캐스터가 도전을 생중계하고, 멈추면 판독 연출 뒤 오차를 1/1000초까지 보여 줍니다.
- 3번 도전한 평균 오차로 칭호를 주고, 칭호 카드를 이미지로 저장하거나 공유할 수 있습니다.
- `Space` 또는 버튼으로 시작·멈춤. 버튼은 누르는 순간 반응합니다.

## stopwatch.html

시작·정지·랩·초기화가 있는 기본 스탑워치입니다. 가장 빠른 랩과 느린 랩을 색으로 표시합니다.
`Space` 시작/정지, `L` 랩, `R` 초기화.
